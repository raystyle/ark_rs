# 2026-09-01 mac 完美收敛

> M1 后续收官：目录型运行时、多二进制、pin 补齐与升级接管，mac 侧 ome 管理域全量实证。

## 做了什么

1. **提取型扩展**：新增 `zip-bin`（zip 内按叶子名取二进制，gh 的 wrapper/bin/gh 结构用）、`targz-dir` / `tarxz-dir`（全量解压不展平，版本目录与运行时树用）；`*-bin` 型与 zip/targz 的 chmod 支持 `extra_bins` 多成员（age+age-keygen、ast-grep+sg、uv+uvx）；`linux_/mac_cdn_asset_pattern` 平台字段族修 vault 各平台资产名差异。
2. **资产结构实证**：下载 zig/rmux/pwsh/gh/ast-grep 真实资产列目录定布局：pwsh 根平（`~/.local/share/powershell/7`）、rmux prefix 树（flatten 一层落 `~/.local` 的 bin/libexec，官方 install.sh 同构）、zig 版本目录根二进制（`~/zig/<ver>/zig`，`bin/` 猜测被实测推翻）、go 的 `go/` 树（targz-dir 落 `~/.local/go`）。
3. **真坑三枚全修**：go/zig 用子命令 `version` 不认 `--version`（toolver 参数表）；无前缀 tag（uv/nushell/zig 等）被 `unwrap_or("v")` 强加 v 前缀致 404（psd1 语义空即无前缀，默认改空）；cdn 分支不看平台 pin（zig/go 裸 install 报「需 --version」，pin_version 兜底 + tag 优先取 pin_tag 修 go 伪 v 前缀）。go.dev 无 per-file `.sha256`（200 是 SPA HTML 兜底），撤掉该增补。
4. **mac 收敛动作**：sops/uv/vault/go mac pin 补齐（pin 回写仓库）；starship 真装（psd1 mac sha 校验 + targz-bin + 验版本全链）；vault 2.0.3到2.0.4、uv 0.12.5到0.12.6 升级接管（sha 回填）；age/ast-grep --force 重装实证 extra_bins 双机制（targz-bin + zip-bin，age-keygen/sg 均 +x）。
5. **终态**：18 工具 locked=installed 全等（含 zig/go/pwsh/rmux 目录型），pwsh 版本对齐（path 态按 ome 注册语义如实 false：符号链接与 hook 注入不计），win-only 工具与 fnm/bun/python/shellcheck（official/brew/uv 布局）如实空态。全门禁绿（test/fmt/clippy/md 三件套/校验器/gnu 交叉 check）。

## 自省

- **猜布局不如验资产**：zig 的 `bin/zig` 猜测被一条 `tar -t` 推翻（二进制在版本目录根）；gh 的 `zip` 会摊出 `~/.local/bin/bin/gh` 也是列目录才看清。目录型工具的布局字段必须资产实证，不可从 Windows 形态类推。
- **`ome pin`（全量）不是视图命令**：当平台 pin 缺失时它会解析并回写。误当 viewer 跑了一次，好在只写了 sops 且解析正确（恰是计划内的 pin 步骤），vault 的 cdn 解析失败把命令截停在第二站。看状态用 `ome status`，`pin` 是写命令。
- 版本探测三态（--version / version 子命令 / 特殊横幅）与 tag 前缀（v/空/release-）是两组独立的小暗礁，真机逐工具跑一遍才全部现形：「完美」没有捷径，就是全量过。
