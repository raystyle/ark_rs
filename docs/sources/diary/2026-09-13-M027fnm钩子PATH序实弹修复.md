# 2026-09-13 M027 fnm 钩子 PATH 序实弹修复

## 起因

- 用户实弹抓 bug：`ark install fnm` 写进 ~/.bashrc 的钩子是裸 `eval "$(fnm env)"`，执行序在 PATH 含 ~/.local/bin 之前，登录 shell 直接报 `Command 'fnm' not found`。要求 ark 侧修源头防再犯，存量已装机器由 omc bootstrap 兜底改写。
- 定位：钩子内容在 `src\install.rs` 的 `ensure_fnm_shell_hook`（O3-b），块引擎在 `src\platform.rs` 的 `ensure_profile_hook`（幂等判据「全文含该行」，块体演进只会追加新块、存量旧块体永不升级）。

## 修法

- 钩子块体改自含语义：`export PATH="$HOME/.local/bin:$PATH"` 后 `if command -v fnm >/dev/null 2>&1; then eval "$(fnm env)"; fi`。根因（依赖 rc 内相对执行序）从构造上消除；守卫缺席静默，if 形态不污染 source 退出码。钩子行收 `FNM_HOOK_LINES` 常量单一权威，platform 测试引同源（防块体漂移测试不红）。
- 块引擎改块体感知 upsert：抽纯函数 `merge_hook_block`（块在位而块体与目标不一致原位重写，存量旧裸钩子重装即自愈升级；旧 ome 标记块迁移为 ark；同标记重复块收敛为一块；块外原文与顺序不动；未闭合起标记按既有家族语义截断收口，doc comment 与测试钉死）。`ensure_profile_hook` 签名 `line: &str` 换 `lines: &[&str]`，只做 IO；全仓唯一调用点同步。
- R016 钩子口径、M027 错条（归 M103，PATH 类）、INDEX M103 行三处同步。

## codex 对线

- 首轮结论：修复无阻断。两条 nit 收编：一，`[ -x ... ] && eval` 守卫在 fnm 缺席时让被 source 的 rc 返回 1，errexit 加非交互 source 的窄面下是本 diff 新引入的状态回归，改 `if command -v` 形态消（顺带把守卫口径从只认直链放宽到 command -v 并集）；二，测试自带钩子行副本与 install.rs 双权威，违 R004 单一权威，收常量。
- 未收的 nit 留档：CRLF profile 一次性归一化成 LF（幂等不反复重写，同族 env 引擎同病）；追加路径块前多一空行（观感级）；profile_path 命中 fish config 时写 bash 语法属既有残留，非本 diff 引入。
