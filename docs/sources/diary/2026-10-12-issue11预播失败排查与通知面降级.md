- [实证] 根因定案：`gh repo view raystyle/ai-cloud` archivedAt = 2026-10-09T05:39:56Z（isArchived=true）。归档仓 REST 写面恒拒而 GET 仍 200，POST dispatches 404；其 catalog-seed cron 10-09T01:13 后停跑为归档关 schedule 的旁证。
- [实证] 排除 token 失效：本机属主（viewerPermission=ADMIN）凭据 POST 同端点（无害事件名 ark-issue11-probe）同收 404；secret `AGENT_UPSTREAM_DISPATCH_TOKEN` 10-02 配入后未动。预评审 H1/H2（fine-grained PAT 到期、吊销）据此排除，H3 改定案（仓归档）。
- [实证] 假性自愈：run 10/11 三工具同版绿跳 seeded=0，`if seeded:` 门使通知腿不跑，红灯潜伏非恢复；上游水位与 R2 域面同版，下次 cron 仍全跳。
- [实证] 下游无消费方：ai-cloud 两 workflow 均无 repository_dispatch 监听；catalog pin 现锚 claude 2.1.287、codex 0.160.0（落后预播两级），五连绿期的 dispatch 亦无落账。
