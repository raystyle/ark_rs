# 2026-09-15 update 漂移收口

## 对线与根因

ohmycloud 舰队三平台实测报障：status HINT「版本落后锁定」持续列工具，update 对同工具称已是最新，批 update 后 HINT 不消。分型回执（宿主实值 pwsh 7.6.5/7.6.6、age、uv、mq）确认全是 installed 落后 pin 的 a 形态。

根因（行级）：status 的 drift 判据是 `installed（探针）!= locked（pin）`（双向不等，main.rs:1067），update 的 skip 判据是 `resolve（云端最新）== pin_tag`（main.rs:1027），**完全不看 installed**，云端无新版时落后装机被 skip 挡住。HINT 文案「落后」名不副实（判据双向不等，本机 hst 探针领先锁也列）。

## 落地

- `toolver.rs`：`PinDrift` 三态枚举（Current/Behind/Ahead）与 `pin_drift` 纯函数（`version_key` 数值段比较；未装与解析失败保守按 Behind，补装自愈）。
- `main.rs` update 的 resolve==pin 分支三态化：一致 skip 原样；Ahead skip 加 stderr 如实报（消提示归数据面滚锁）；Behind（含未装）补装 pin 版落到 install_tool。stdout emit 块契约未动（仅 stderr 文案扩）。
- HINT 文案改「版本与锁定不一致，升级或滚锁」。
- MSI 型确认：pwsh 条目 `extract="msi"`（装 Program Files 系统位），Behind 补装走 msi 升级装，路径可行。

## 尾二修：宿主残留两笔

- git（update 称已最新但 HINT 仍列）：status drift 用字符串等值、pin_drift 用数值段，git for windows 探针 `2.55.0.windows.5` 对 pin `2.55.0` 数值等（parse_semver 剥非数字尾巴）字符串不等。修：status drift 判据统一走 `status_drift_hint`（内部 pin_drift 数值口径）。
- omc（npm tgz 从未发布，HINT 恒挂）：裁 npm-tgz 类不进 HINT，版本真源在 npm registry（端上 npm 自管），catalog pin 不构成端上 drift 判据。
- 单测：git 后缀形态 Current、npm-tgz 排除、领先列、缺值不列；全量 143 单测加集成面绿。
- 记档曲折：heredoc python 断言失败后换行顺序执行放行门禁与推送（db6c65c 代码先行），登记随后补，命令块内语句必须 `&&` 串联或分次执行。
