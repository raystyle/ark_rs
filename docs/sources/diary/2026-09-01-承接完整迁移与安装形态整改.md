## vsbuild 接管

- **feat**：用户问「ohmyenv 有没有 vsbuild 之类结构」并指示接管。核实两仓 catalog 均无 vsbuild（ohmypwsh 走 `scripts\set-vsbuild.ps1` 专用脚本），属 P0026 差集盘点漏掉的「脚本专域散兵」。新增 `src\vsbuild.rs` 与 `extract = "vsbuild"` 条目型：永续引导器（aka.ms 无版本无 sha）无 pin 语义、install 幂等（cl.exe 在位即跳过）、未提权经 gsudo 重跑（退出码透传）、PATH 写机器级 HKLM（MSBuild 与 cl 目录）、探测用跨版本稳定的 MSBuild.exe（`-version` stdout 首行裸版本，中文横幅兼容）。platform 补 `is_elevated`、机器 PATH 读写与 `merge_path_entries` 纯函数；pin/update/daily/query/package 五命令面 evergreen 守卫。
- **踩坑**：`which::which` 返回 Result 不是 Option；`Tool::extract()` 已返回 `Option<&str>` 再 `.as_deref()` 触发 needless lint。
- **实证**：74 测试全绿、fmt/clippy 零告警；真机 `ome status` 出 `installed=17.14.51 path=true`（机器级 PATH 判定），`ome install vsbuild` 幂等空转 exit 0 无 UAC，`package vsbuild` 正确拒绝 exit 1。Windows SDK 仍走 ohmypwsh ISO 分离（set-windows-sdk.ps1），不进 ome。
