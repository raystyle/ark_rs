# 2026-08-31：ome 扩展 Linux 本机部署支持

## 今日工作

1. **立项扩展 Linux 支持**
   - 用户确认将 Linux 纳入 ome 管理域（除 agent 外），与 Windows 并行。
   - 更新 `AGENTS.md` 边界与管理对象、`GOAL.md` / `PLAN.md` / `TODO.md` 立新目标。

2. **平台抽象层 `src/platform.rs`**
   - 集中封装 EnvRoot 默认路径、PATH 管理（Windows 注册表 / Linux shell profile）、环境变量展开、official 判定、self-deploy 目标。
   - `envpath.rs` 改为 re-export platform 的 PATH 管理，保留 Windows PATH 纯函数。

3. **catalog 平台扩展**
   - `Tool` 增加 `linux_repo`、`linux_asset_pattern`、`linux_dir`、`linux_bin`、`linux_exe`、`linux_extract`、`linux_sums_pattern`、`linux_asset_sha_suffix`、`linux_bootstrap_asset`。
   - 提供平台感知方法，Linux 优先 `linux_*`，缺失回退通用字段。

4. **安装/提取/状态 Linux 适配**
   - `install.rs`：支持 `~` 与环境变量展开、Linux 不整删共享 bin、防穿越允许 `$HOME` 之下。
   - `extract.rs`：Windows 专属类型加 cfg；Linux 设置可执行权限；新增 `targz-bin`；修复 `flatten_single_wrapper` 自覆盖冲突。
   - `toolver.rs`：Linux `exe_path` 基于 `linux_dir`；`expand_env_vars` 支持 `$VAR` / `${VAR}`。
   - `checksum.rs`：跨平台 asset 不一致时不使用 pin 的 sha256。
   - `selfdeploy.rs`：Linux 下复制到 `~/.local/bin/ome`。
   - `status.rs`：PATH 查询与 exe 路径走平台抽象。

5. **catalog Linux 字段落地**
   - 已为 jq、age、gh、rg、sops、yq、starship、just、ast-grep、nushell 添加 Linux 字段并验证 query / install。
   - 本轮补齐剩余工具：pwsh、7z、dotnet、fnm、bun、uv、python、mq、herdr、rumdl；aria2 / git 明确无官方 Linux 预编译资产，由系统包管理器维护。

6. **本轮新增能力**
   - `extract.rs`：新增 `tarxz-bin`（7z Linux）、flatten 支持共享 bin 目录内已有其他文件、递归 flatten 避免误 flatten legitimate 子目录。
   - `catalog.rs` / `resolve.rs`：新增 `linux_cdn_url`，支持 dotnet 这类 cdn 来源的 Linux 直链。
   - `checksum.rs`：校验清单支持 UTF-16 LE/BE（PowerShell `hashes.sha256` 为 UTF-16 LE）。
   - `install.rs`：bootstrap 资产下载仅 Windows 下执行（7z-extra 专用）。
   - `toolver.rs`：Linux `exe_path` 保留 `linux_exe` 子目录（如 python 的 `bin/python`）。

7. **测试**
   - 新增 `tests/linux_install.rs`：jq install/deploy/status 闭环 + PATH 幂等。
   - Windows 语义测试加 `#[cfg(windows)]`。
   - `cargo test` WSL 全绿；`cargo check --target x86_64-pc-windows-gnu` 通过。
   - 手动沙盒验证：pwsh / 7z / dotnet / fnm / bun / uv / python / mq / herdr / rumdl 均能 `install --latest` 成功并读出版本。

8. **文档**
   - 更新 `README.md`、`docs/references/R001`（补充 `linux_cdn_url`、`tarxz-bin`）。
   - 跑 `md-ref-scan.py` + `md-heading-scan.py` 全绿。

## 关键决策

- Linux 采用系统标准目录：ome 元数据在 `~/.local/share/ohmyenv`，单二进制默认到 `~/.local/bin`，复杂运行时（pwsh/dotnet/python）使用独立子目录；PATH 通过 `~/.bashrc` 管理。
- 跨平台 catalog 以 `linux_*` 字段并列，缺失回退通用字段，保持向后兼容。
- 新增 `targz-bin`、`tarxz-bin` extract 类型处理带包裹层/杂项的归档包。
- aria2 / git 在 Linux 不由 ome 接管：官方 release 无适合 Linux x86_64 的预编译资产，继续由系统包管理器负责。
