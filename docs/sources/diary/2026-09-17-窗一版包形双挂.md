## 实现面

- selfupdate 读序四层：包形主名先（净 triple 去 .exe 尾，win zip 他 tar.gz）、gnu 裸件回退臂次、msvc 再次、ome 兼容殿后；官方名序与镜像尝试表同步；dev 滚动源无包形自然落裸件层
- 包形判新（设计决策落定，优于 REQ 原记的版本等值方案）：digest 是归档 sha 不与本地 exe 直比；归档经锚校验下载后解包取内层二进制（拼名契约 ark-<净triple>/ark(.exe)），等值判定在解包后二进制间进行，判新机制不动（无版本 plumbing 无混用语义），代价是 current 检查也要下一次归档（self update 低频可接受）
- release.ps1 -IncludePackages 开关（缺省裸件单形 = 2.2.0 终版形，两不相扰）：包形构建（单顶层目录直放二进制加 README 加 LICENSE；zip 走 Compress-Archive）加包形冒烟（解包拼名命中、包内二进制与裸件 sha 逐字等、linux 与 win 本平台直跑逐字对、mac 内容等价断言）
- seed.py 包形到则灌（missing_ok 面 phase 无关，无需旗标与版本阈值）；skip 分流（裸件 skip 进红灯与清出话术、包形 skip 落 INFO 常态）
- LICENSE 入仓（MIT，包形契约件）；AGENTS 补 self update 双通道开放口径（差10收口）
