# 2026-09-10 typst 入册与 v0.15.1 锚核验

## 起因与范围

- 用户指令「增加 typst v0.15.1 的安装」，点名 release tag（`github.com/typst/typst/releases/tag/v0.15.1`）。
- 范围：catalog 入册（三平台静态字段加 pin 四键）、计数同步、本机真机安装验收；不改 CLI 命令面（D10 三原语口径不动）。

## 锚核验

- 上游 release 资产列表无 SHA256SUMS / checksums（无统一校验清单），锚形态取 GitHub digest（lightpanda D24 先例）。
- 三平台资产本机下载实测 sha256 与 digest 逐字一致：win `typst-x86_64-pc-windows-msvc.zip` 19CE3551、linux `typst-x86_64-unknown-linux-musl.tar.xz` A6D077D0、mac `typst-aarch64-apple-darwin.tar.xz` 48F62ED0。
- 多架构同名族防错配（M014 同型）：`aarch64-pc-windows-msvc`、`x86_64-apple-darwin`、`riscv64gc`、`armv7` 等旁支资产逐个对照名字与 digest 行，不按命名惯例推断。

## catalog 节与布局

- 归 cli 类（命令工具依赖），节尾入册；探测走 `typst --version`（实测输出 `typst 0.15.1 (9dfd3a08)`），正则 `typst (\d+\.\d+\.\d+)`。
- win zip 内含 `typst-x86_64-pc-windows-msvc/` 单包裹层，`extract = "zip"` 展平后 typst.exe 居 dir 根；linux / mac 的 tar.xz 各为单二进制，`tarxz-bin` 按叶子名取 typst 落 `~/.local/bin`。
- mac 取 aarch64 资产（ome mac 为 ARM）；上游另有 x86_64-apple-darwin，不设 Intel 字段。

## 顺修与反馈核实

- clippy 存量告警修（单独成笔）：`src/catalog.rs:448` doc 注释第二行 `>` 起首成 markdown 引用、第三行续接触发 doc_lazy_continuation；D31 提交带入，CI 只跑 cargo test 故未暴露，第三行补 `>` 后 clippy 全绿。
- `seed.py` 边车落源目录修（M015，单独成笔）：`--plan` 跑完工作树多出未跟踪 `catalog/tools.toml.sha256`（沙滚段 helper 直写 `local_asset.parent`，catalog 本体的 parent 即仓库 `catalog\`）；抽 `stage_sidecar` 加临时目录包住上传循环，两个上传 helper 同改，域面对象与键名零变化。
- PATH 反馈核实（用户报「D:\ohmyenv 下几十个子目录都注册了 PATH，唯独没加 \typst」）：注册表 `HKCU\Environment\Path`（REG_EXPAND_SZ，1652 字符）首条即 `D:\ohmyenv\typst`，机器级 PATH 只有 docker 与 vsbuild 两条（用户级为工具面一贯口径）；本会话进程 PATH 缺 typst 属已开终端的环境快照（install 当刻的 `std::env::set_var` 只改 ome 自身进程，广播对已运行终端无效）；用注册表用户与机器 PATH 拼新环境起 pwsh 实测 `typst --version` 正常（0.15.1），即新终端生效。M011 增补同型：已开终端不刷新是 Windows 语义，非注册缺失。

## 推送与镜像入镜验收

- 用户令「推」：五笔提交推 main（`e19422e..8b6547b`），CI 双 workflow 触发。
- build workflow 三平台测试 job 全绿（ubuntu / windows / macos），mirror-r2 路线 A 随后跑。
- seed-mirror 路线 B 绿（1m21s）：`[sync] typst` 三件 sidecar-missing 后上传，汇总 `{"total": 101, "synced": 98, "uploaded": 4, "failed": 0}`（4 = typst 三资产加 catalog 本体）。
- 镜像复核：typst 三资产与 `.sha256` 边车均 HEAD 200，边车 sha 与 catalog pin 逐字一致（19ce3551 / a6d077d0 / 48f62ed0）；镜像 `ome/catalog/tools.toml` 的 sha 与仓库 catalog 相等（cff2b44a…），且含 `[tools.typst]` 与 v0.15.1 段。
- 本机 `seed.py --plan` 复跑：101 对象 99 synced（typst 三件已转 synced），余两条为瞬时网络抖动（gitleaks darwin 报 unreachable、herdr 0.8.2 mac 报 asset-missing，复检 HEAD 均 200），非真实差集。
