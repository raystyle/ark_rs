# 2026-08-31：开发主机由 WSL/Linux 切换到 mac

## 背景

ome Linux 本机部署支持已收官（见 `docs/diary/2026-08-31-ome扩展linux本机部署支持.md`）。用户决策将后续开发主机从 WSL/Linux 切换到本机 mac，需要更新文档与三原语，让 mac 侧可独立接手。

## 今日工作

   - 文件：`docs/references/R011-mac开发接管-环境准备与构建验证.md`。

## 关键决策

- 不新增 mac 专属代码分支：ome 已有 `#[cfg(not(windows))]` 覆盖 Linux/macOS，mac 接管以文档切换和真机验证为主。
- mac 同时承担「开发主机」与「被管理目标」：与 Linux 阶段一致，元数据用系统标准目录，单二进制默认到 `~/.local/bin`。
- Linux/WSL 保留为验证机：防止 mac 与 Linux 行为分叉，后续仍需在 WSL 跑 `cargo test` 回归。
