# REQ-0019:三层聚合对齐迁移con-04

## 边界与分工

- 历史 diary 不回写（迁移形明文）；CHANGELOG 旧条目同属历史不改写，旧路径字样冻结保留。
- 标准面加载视图取投影拷贝形（非符号链接）：仓为 Windows/WSL 双面检出，git 符号链接在 Windows 检出需特权，投影加同步守卫跨端稳态。
- 候选标准 skill 以「待审」标记入库而非留未提交工作区：herdr 跨会话人裁通道下未提交态跨会话不可靠；拒绝即移防重提页加标准面还原（纪律句在 AGENTS）。
