# M109:同进程并行临时目录互踩

## PROBLEM

测试与安装代码用「工具名加进程 pid」命名解包临时目录（ark-copy-bin-{tool}-{pid} 形），同进程内并行跑的两个用例（cargo test 多线程同 pid）互相 remove_dir_all 对方的临时目录，出现随机「打开资产失败: decoded: No such file or directory」与解包成员缺失，重跑结果不定。

## ROOT CAUSE

临时目录唯一性只取进程级粒度（pid），未取调用级粒度；同进程并行（测试线程、并行 install）下 pid 恒同。仓内既有同型隐患：extract_tar_single_binary 的 ark-{kind}-bin-{tool}-{pid} 同形命名（现无同工具并行用例未触发）。同根因家族：ADR-0005 附录（工具与脚本的可并行性缺陷类）。

## FIX

临时目录名带纳秒时戳或单调计数取调用级唯一；同进程并行是多线程测试的常态假设，不是偶发环境。
