# R015：软件清单发布更新与播种标准

> 角色：现役标准。ark 软件清单（`catalog\tools.toml`）的**发布、更新**与**软件资产播种**三流程的唯一流程权威；字段与 pin 语义在 R001，跨仓协调与段域在 R014，签名方案研究在 S006，测试闸门在 R004 三.6。2026-09-10 定档（D32/D33/D34 收口后成文，D35）。

## 一、角色与信任链

| 角色 | 承担 |
| --- | --- |
| 仓库 `catalog\tools.toml`（D37 已退役） | 本仓不再持有权威件；入册走 omc 数据面（其仓 `catalog/tools.toml` 加 catalog-lint 四规则门），本仓只保留 R001 格式契约与 `tests/fixtures` |
| 云端 `ark/catalog/`（env.ohmygh.com） | 运行态权威：清单本体、`.sha256` 边车、`.minisig` 签名件三件套。D41 起主键 `ark/catalog/`、端上兼容读 `ome/catalog/`（键读序主先兼容后；停 ome/ 键判据为存量机水位清零） |
| `.sha256` 边车 | 传输完整性锚（种子端自官方资产或清单自算即锚） |
| `.minisig` 签名 | 来源真实性锚（Ed25519；公钥内嵌 ark 二进制，当前 `FB93BFD3788C2316`；轮换走内嵌集合过渡） |
| 私钥 | 只在开发机 `~/.config/ome/` 与 GitHub Secret `CATALOG_SIGNING_KEY`，永不入仓。D41 裁定：密钥位**保留不迁移**（密钥材料零扰动，与 EnvRoot 物理目录同类；后续轮换时再议） |

## 二、清单发布：数据面到云端

权威与发布运营在 ohmycloud（D37 终版）：权威 `catalog/tools.toml` 落 ohmycloud 仓（初值自本仓复制，遵循本仓 R001 格式契约），catalog-lint 四规则门（vitest 形态）进其 CI 首步，catalog-seed 流水签名发布云端三件套并播种资产域（批 2 移植 seed.py 域面 diff 逻辑，其仓权威单源）。

ark 侧义务收缩为：改消费面（新 extract 类型或新字段）时以 R001 契约 herdr 知会 omc 同步 lint 与数据；端上验收 `ark catalog sync` 后 `signature=valid`。

## 三、清单更新：云端到端

| 通道 | 语义 |
| --- | --- |
| `ark catalog sync` | 显式刷新，不受 TTL 与 `ARK_OFFLINE` 限制；也是修复通道 |
| TTL 自动刷新 | 仅用户数据副本；默认 24h（`ARK_CATALOG_TTL` 可改，0 关；`ARK_OFFLINE=1` 等效关）；单次 5s 探活加 `.last-sync` 退避标记 |
| 裸端自举 | 四级解析全 miss：只走云端镜像同款三重门（键读序 ark 主先、ome 兼容回落）；镜像不可达即 fail-closed 报错（提示网络与 `ARK_CATALOG` 出路），无免验兜底 |

- **三重门（落位前缺一不可）**：边车 sha 锚比对、`Catalog::load` 解析、内嵌公钥验签；任一不过拒收。
- **落位纪律**：临时名随目标派生（`tools.toml.tmp` 与 `tools.toml.minisig.tmp`）；先清单后签名件。
- **加载前巡检**：invalid 阻断全部非 catalog 命令（含 self update，防被篡改面自我升级）；missing 仅用户数据副本告警；catalog 子命令整组豁免保自愈。
- **本地回写**：pin/update 改写即撤签名（内容已变，不留假凭证）；下次 sync 恢复。
- **升级 runbook**：跨版本 self update 后带一次 `ark catalog sync`（旧版孤儿签名为一次性迁移伤痕，0.3.0 起条件化撤签名防复发）。

## 四、软件播种：资产到云端

| 路线 | 触发 | 段域 |
| --- | --- | --- |
| A 自产 | push main、push v* tag、workflow_dispatch | main 灌 `ark/dev` 加 `ome/dev` 双沙滚段；v* tag 灌双 stable 段（D41 B 双写：ark/ 段配 `ark-*` 主名资产、ome/ 段配 `ome-*` 兼容名，同 job 两族各跑一次 seed.py；段名与 self update 通道同名；`ome/latest` 已退役；停 ome/ 段与撤 `ome-*` 资产名判据为存量机水位清零） |
| B catalog | ohmycloud catalog-seed（dispatch 加 6h 定时；本仓 seed-mirror 已整撤） | 其仓权威清单的软件资产 `/<tool>/<version>/<asset>` 加边车；`ark/catalog/` 三件套（清单加边车加 `.minisig`；D41 起主键，兼容键 `ome/catalog/` 由 omc 铺段前维持供给，端上键读序主先兼容后） |

- 无 sha 不入镜（pending 队列）；边车自算即锚；rclone NO_CHECK_BUCKET 必带；Cache-Control 60s 加消费侧 `?v=`/`?t=` 击穿双保险。
- **ziglang index 形态与版本去锁（D43，2026-09-13）**：`cdn_index_url` 指向 ziglang.org/download/index.json 类索引时（顶层键即版本、per-target `tarball`/`shasum`/`size`），`cdn_asset_pattern` 匹配 **target 键**（如 `^x86_64-windows$`）；**无 pin 条目默认 latest**（install/update 解析最新，键滤 `+` 变体与非 semver）；`shasum` 为官方 sha 直值锚（引擎 `Resolution.official_sha256`，校验与镜像锚共用）；布局字段（`bin`/`exe`）支持 `{version}` 占位（探测 glob 取 semver 最大在位版本、装后与 PATH 按解析版本定版）；`cdn_url` 模板退役（tarball 直取 index）。
- 消费侧（D44 反转 2026-09-13 加 D51 全链转正 2026-09-18 用户裁定，详篇 ADR-0008）：镜像 env.ohmygh.com 为默认通道，GitHub 降兜底。下载层镜像单次快速首试、官方完整链兜底、有锚（catalog pin、版本段边车或 latest 边车）必校验；**解析面（D51）**：pin 驱动（install/update/query/heal 默认路径）零 GitHub API，catalog pin 三键在位即镜像资产域直装、GitHub release 确定性直链兜底（`Resolution.fallback_url`），pin 三键缺一或显式 `--latest`/`--tag`/`--version` 才打 API；**独立分发域（REQ-0013）**：五工具（ark/hst/officecli/reader/browse）有专属域（节键 `mirror_domain`，reader 自有桶 reader-dl、其余 env 桶多域），在位即该工具镜像基址走专属域、缺省回落 env 域，键形与边车不变（原 D38「API 失败回落镜像」被默认通道收编删除）；**selfupdate（D51）**：元数据镜像段读序先行（边车即锚）官方 API 兜底；update 解析对齐 catalog pin（云端最新定义指镜像与 catalog，D49 三态不动）；开关 `ARK_MIRROR`：`=1` 转正默认兼容 no-op、`=0` 官方优先逃逸阀（下载跳镜像首试、selfupdate 反转读序）。

- `ome/latest` 旧段已下架（2026-09-11 ohmycloud 执行，env 桶余 catalog/dev/stable 三段），S017 O1 至 O7 双仓闭环（ohmycloud cb7a5cb 终态文档）。
