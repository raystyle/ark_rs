# ADR-0009:三层聚合对齐迁移

## Context

仓内文档体系自 ADR-0001 起为 docs 全家桶平铺（adr/requirements/references/research/proven/diary/guide），与 distil-skill v2 三层聚合标准（sources 唯一出处层、knowledge 双链知识层、operations 标准面，单向支撑）不对齐：无层根、G 族 how-to 手册未归标准面、无防重提页与蒸馏流水、无模式页承载。distil-04 实践反馈轮已摸清差距（八元组过五缺六、建仓五步过一缺四），v2 已补既有仓迁移形（旧名映射注记加 git mv 保史加现役面引用同步，历史轨迹不回写）。

备选项：维持平铺不迁移（差距永在，蒸馏环无法起步）；或推倒重来重建三层（违背迁移形，58 篇 diary 与全量交叉引用破链）。用户经总台施工单裁定按 v2 迁移形对齐。

## Decision

1. 层根 docs/ 中心形三层：`docs/sources/`（diary 加 proven 加 external 立位）、`docs/knowledge/`（adr 加 req 加 references 加 research 加 mistakes 立位加防重提页与流水）、`docs/operations/`（G 族迁入加 skills 子面）。目录迁移一律 git mv 保史；现役面引用同步改新路径；历史 diary 不回写（其旧路径字样按轨迹冻结保留）。
2. 归档统一按 v2 字母表：requirements 改名 req（判例实测）；G 族（how-to 标准手册）自 guide 迁 operations 并整族一案补闸（页头知识底座链加族级闸门记录段）；M 编号坑模式独立立位 `knowledge/mistakes/`（原并入 ADR-0002 至 0006 附录的 M001 至 M106 留存，新页自 M107 续号不复用）。
3. git 边界取单仓纪律形并写进 AGENTS：knowledge 面（`docs/knowledge/`）先于标准面（`docs/operations/`）独立成 commit；闸门拒绝只回滚标准面与加载视图（`.claude/skills/`），knowledge 路径永不 reset；知识层永不回滚，否证走新版本或 supersedes 注记。
4. `.gitignore` 划界放行 `.claude/skills/`（其余 `.claude/` 仍整体忽略），作为标准 skill 的加载视图投影位，同步守卫挂 `.tools/llms-guard.py`。
5. 根 `llms.txt` 代码文件位置表挂漂移守卫（同 llms-guard）替代手维护无守卫态。

## Consequences

- 好：三层单向支撑落位，蒸馏四步环可起步（首轮试点随本批）；G 族归层与 v2 字母表一致；knowledge 永不回滚纪律有成文载位；llms 模块表与技能投影有守卫。
- 代价：全仓现役面引用一次性同步（AGENTS/llms/README/PRD/GOAL/TODO/INDEX 与 ADR 交叉引用）；外部若有深链旧路径会断（仓内以旧名映射注记兜底）。
- 风险与缓解：历史 diary 内旧路径字样与新结构不一致属冻结轨迹的固有形态（迁移形明文豁免）；后续蒸馏产物（模式页、标准 skill）全部走新层位。
