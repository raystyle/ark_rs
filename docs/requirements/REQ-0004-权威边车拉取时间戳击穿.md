# REQ-0004:权威边车拉取时间戳击穿

## Scenario

reader_rs REQ-050 观测 lan-ubuntu 裸端 bootstrap 拿旧 pin，初判根因为 resolve_cloud_sha 权威边车拉取裸 URL 无击穿 query（`cloud_sidecar_url` 注释的设计意图未落实到该调用点）。

## Criteria

- [x] 初版实现：权威边车拉取补 `t=<unix 秒>`（抽 authoritative_sidecar_url 纯函数加单测）
- [x] 对线驳回（codex 实证）：`mirror_sidecar_sha` 的 fetch 层 `mirror_sidecar_anchor_fast`（996d342，2026-09-08 起）内部已带 `t=` 击穿，入参裸 URL 只是错误串显示形态，「唯此跳漏」的 RCA 不成立，call-site 加 t 属冗余双写
- [x] 处置：call-site 双写撤除（恢复裸 cloud_sidecar_url），authoritative_sidecar_url 与其单测撤；顺带修 `parse_sidecar_sha` 错误串印实际请求 URL（防同型误判再犯）
- [x] bootstrap 旧 pin 真根因待定：候选为 CF 对该域缓存键忽略 query 参数（t 击穿整体失效）或 R2 覆写对象传播滞后，归 omc 数据面域配置排查（另立 RCA）
