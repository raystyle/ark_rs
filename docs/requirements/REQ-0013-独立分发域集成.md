# REQ-0013:独立分发域集成

总台派单（2026-09-19，用户令「ark 要集成有单独域的 CLI 升级」）。五工具有独立分发域（与 omc 仓 TOOL_DOMAIN 表同源，用户裁 2026-09-17）：ark/hst/officecli/reader/browse 五域，键形 `/<tool>/<version>/<asset>` 加 `.sha256` 边车不变；reader 自有桶 reader-dl，其余 env 桶多域。

## Scenario

独立域工具（如 reader）镜像腿打 env.ohmygh.com 只能 404 走官方兜底，违背镜像优先缺省；ark 解析面须按 catalog 节键用专属域作该工具镜像基址。

## 设计 总台裁决 未改

单一真源 = 云 catalog tools.toml 各工具节可选键 `mirror_domain`（总台并行滚入并重签）；ark 读键作镜像基址，缺省回落 env.ohmygh.com；仓内禁第二份域表。ark 自更新通道未用独立域（走 env 桶 ark 段），按裁决保持不动。

## Criteria

- [x] catalog 新键 mirror_domain（Option 字段加 mirror_base() 访问器：非空即专属域、空串/空白/缺省回落 env 域）
- [x] 解析面：pin_direct 镜像主通道 URL 基址取该键（resolve 单测独立域/回落/空白三态）
- [x] 下载面：download_asset_with_mirror_at 显式基址形（install 主链与 npm-tgz 两腿接线 def.mirror_base()；docker/evergreen/selfupdate 保持 env 域：无专属域键）
- [x] 仓内零第二份域表（域值只存在于云端 catalog 与测试期望值）
- [x] 帮助面与 --llms 表述覆盖独立域事实且零内部编号
- [x] 测试三层：单测（两面各一例加边界）、集成（临时 catalog 带键 query url 断言专属域）、实弹（ark catalog sync 后 update reader 走 reader.ohmygh.com，锚校验照旧）

## 改向记录（2026-09-19 总台改令）

用户裁「自维护自升级 CLI 走 CLI 自升级渠道、其余对齐 omc 维护 env」，下载腿方案被 REQ-0014 委托形态取代：mirror_domain 键留作 omc 侧元数据真源、ark 不消费下载（键不删不阻），仓内仅保字段解析（旧 catalog 无键兼容、云键在册可读）与 R001 契约行；下载腿接线（mirror_url_at 消费、install 两腿、访问器）已撤回。本 REQ 判据面按改向后状态复核：键解析面达成、下载面判据由 REQ-0014 承接。
