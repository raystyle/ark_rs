# REQ-0017:官方上游定时预播与R2版本段播种

## Scenario

舰队 claude 与 codex 等工具的版本面归 ark 单通道（用户三裁 2026-10-02：ark 是自己离线安装、分发走 R2 env.ohmygh.com 域；在 ark_rs 用 GitHub Actions 定期离线下载官方最新版再 R2 发布）。需要在 ark_rs 仓内自动完成官方最新版的解析、下载、校验与 R2 版本段预播，替代人工种子节奏，并以 repository_dispatch 通知 ai-cloud 仓接 catalog bump。

## Criteria

- [ ] 新 workflow `.github/workflows/agent-upstream.yml`：双频率层落地（tier=agent 每日 cron、tier=cli 每周一 UTC 加跑，层裁在岗内 date 判；dispatch 可显式 tier=all 补跑加 tools 名单过滤）
- [ ] 清单驱动 `.tools/agent-upstream.toml`：22 工具入册（agent 层 claude/codex/kimi；cli 层 gh/rclone/uv/jq/yq/rg/just/zoxide/starship/ast-grep/gsudo/mq/rumdl/gitleaks/age/sops/typst/nushell/fnm），三平台资产名与 sums 策略在册，不依赖 ai-cloud catalog 未补齐字段
- [ ] 同版绿色跳过：域面 HEAD 比对 `<domain>/<tool>/<version>/` 全资产加边车双在位即跳过（R2 即已播记录，零仓状态回写；只比资产会把边车传失败的半灌态永久掩盖）
- [ ] 官方 SHASUMS 逐件校验：combined（清单键按全名加 basename 双形对齐，兼容 mq 的目录前缀键）与 sidecar 两形实校；none 形（官方无清单：zoxide/ast-grep/age/typst/fnm）自产边车为唯一锚并 WARN 注记（rclone 官方有 PGP 签名 SHA256SUMS，归 combined）
- [ ] 灌段形：版本段 `<tool>/<version>/` immutable 加自产 sha256 边车（rclone v1.75.1 pin，配方同 r2-seed.yml）；stable 段绝不触碰（R008 分工）
- [ ] 防半灌：任一资产缺或校验不符即该工具整体不灌记失败，终局退出码 1；workflow 失败自动落 gh issue 写明资产名与期望差（同日同题开单追加评论不重复建档）
- [ ] 预播成功后 repository_dispatch（事件 `agent-upstream-seeded`，payload 出工具加版本加逐件 sha 加 run_url）；`AGENT_UPSTREAM_DISPATCH_TOKEN` 缺省 WARN 不红（配置后下次生效）
- [ ] 本仓门禁四件套加 dev-evo check.py 绿；对线评审 codex 轮至 CONFIRM

## 边界与分工

- minisign 签名与 catalog seq 门在 ai-cloud catalog-seed 面（私钥不在本仓，架构上不可触碰）；本件只预播软件资产版本段。
- catalog 的 guide_notes 旧口径（claude 升级走自身更新）改写与锚版本 bump 属 ai-cloud catalog bump 批（总台并行推进），不进本 REQ 面。
- 舰队存量原生安装归一迁移（install --force、遮蔽清理）属后续 P1 批，本 REQ 只铺预播地基。
- `--plan` 预演只覆盖 latest 解析与域面比对，不触官方清单与资产下载（combined/sidecar 校验路径首 run 回执补证）。
