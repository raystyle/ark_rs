# REQ-0014:委托自升级通道

总台改令（2026-09-19，用户裁「我们自己维护的自升级的 CLI，ark 对齐也走 CLI 自升级渠道；其余不是我们维护的 CLI 对齐 omc 维护 env」，取代 REQ-0013 下载腿方案）。

## Scenario

家族五员（ark 自身、hst、browse、reader、officecli）是有独立域与自升级面的自研 CLI；ark update 对其不再自建镜像下载腿，改为委托调用各 CLI 自身自升级命令（家族标准形锚校验回滚自证全数继承）；其余非自研工具照旧 env 镜像优先加官方兜底。

## 设计 总台改令 未改

- 委托命令面（四员本机 --help 实测）：hst `self update`、browse `update`、reader `self update`、officecli `__update-check__`（内部自升级入口，检新并自更）；ark 自身走既有自管分支提示 `ark self update`。
- 让位契约联动（家族仓零改动）：委托前临时撤 ark-managed 落痕（rename 挪开保内容）、自升级完成（含失败）后恢复；家族让位互锁实弹验（reader 直跑 self update 被落痕拦、CTA 指回 ark）。
- catalog mirror_domain 键留作 omc 侧元数据真源，委托形态不消费下载腿；键不删不阻（ark 侧字段在位保解析与 R001 契约）。
- 无参全量：五员走委托腿、其余镜像腿，同批混合输出 channel=self-update 如实标注（镜像腿缺省无 channel 字段）。

## Criteria

- [x] 路由单测两面：家族员工具名路由委托腿、非家族路由镜像腿（None）
- [x] 撤痕复痕舞蹈测：伪家族 CLI 断言执行期落痕不在位、完成后原样恢复、无 .bak 残留
- [x] 未装回落：家族 CLI exe 缺位回落镜像安装腿首装
- [x] 机读面：委托行 action=updated/failed 加 channel=self-update 加 version 探活；失败单工具 exit 1、all 循环计失败项
- [x] 帮助面与 --llms 如实（家族=委托自升级、其余=镜像）零内部编号
- [x] REQ-0013 改向记录与键不消费说明

## 对线裁定补充（一轮）

- --force 对四员不作用（家族腿不吃 force；force 真装钉版需求走 install --force），帮助面已注明。
- C1 裁：reader 首装接受镜像未命中走官方兜底（env 段无 reader 对象、键不消费，仓内零第二份域表；官方腿可用）。
- C2 确认：四员 update 目标为家族 latest（改令语义），pin 漂移领先由 omc 滚锁消；hold 仍拦（判定序在委托前）。
- C3 备案：探活与真身定位同尺（exe_path 优先 PATH 兜底，与 status 一致）。
- officecli 委托副作用备案：更新到 upstream latest（非 pin）并重置其 24h 检查节拍（LastUpdateCheck），属其自升级原生语义。
