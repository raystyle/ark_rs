## 总台派单

## 实现（472750a）

- stable 通道家族形：官方 latest API 一次判新（tag 加 digest，镜像段资产名不带版本无法反查）加 semver 门（Current/LocalNewer/Upgrade，localNewer 不动）加镜像 stable 段下载优先；dev 通道维持 D51 镜像元数据优先（边车同源锚不符硬拒）。
- 自替换五小件：同目录暂存与备份 ark-new/old-<pid>（全程 rename，POSIX 亦有备份）、.ark-selfupdate.lock（create_new 原子取加 pid 活性检测加死锁收割）、陈旧残留清扫（归属 pid 判活再清）、--version 自证五次重试（stable 断言远端版本、dev 断言可执行）、证败回滚并复核加自救路径。
- ark-managed 落痕：绿色主链与 official 型真身同目录落标记（内容 ark 版本号，幂等）；资格纯函数排特型（npm-tgz/uv-git/msi/自管）与相对路径。
- 件三实证：browse self update 0.6.0 到 0.7.0 后本机 ark status installed=0.7.0 与 browse --version 同报（status 实值探活本就达标；locked 待总台滚 catalog）。
