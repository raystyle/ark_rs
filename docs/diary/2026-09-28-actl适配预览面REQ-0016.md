# 2026-09-28 actl 适配预览面与 llms 适配说明

## 总台派单两件

背景：ai-cloud 框架 e76d84d 起 actl 对 ark 透传适配（lib/passgate.ts，不改 ark 本体）：`actl ark <长尾>` 原样透传，写级动词过 actl 写闸预览（`--json` 出 TOON 信封，`--yes` 由 actl 消费剥离）。写闸只预览 exec 行，工具自带预览才能见真计划；hst_rs 侧同类件随其 v2.9.8 落地可参照。

1. install/update 补 `--dry-run` 真计划（版本、资产与 sha、解压目标、PATH 注册面，不落盘）。
2. `ark --llms` 补 actl 适配说明行（措辞参照 hst v2.9.8 形）。

## 实现 REQ-0016

- `--dry-run` 计划块：tool/action=dry-run/would（install/skip/delegate）加 tag/version/asset/size/url/fallback/sha256/dir/bin/cache；update 面另出 drift 三态（current/ahead/behind，与真跑 D49 同尺同 INFO，update_plan_state）；早退分支计划块与真跑块同源一处构造（skip_rows 防两形漂移）。
- 零写副作用边界：解析面照常（pin 驱动零网络）；幂等预测只读探测与 status 同尺；sha 只给离线已知锚（checksum::offline_expected_sha256 抽离，expected_sha256 复用同前缀防双份漂移），官方清单类校验源不预取（预览不落盘红线，空串表示下载期校验）；家族委托腿 locate_exe 抽 pub（run 与 dry-run 共用判据），dry-run 不调用家族 CLI。
- `--llms` actl 行：独立直用完全不变；经 actl 调用时写级动词（install/update/heal/init、pin 设锁形、catalog sync、self update，对齐 passgate ARK_RULES）过其写闸（预览缺省，加 `--yes` 执行），`--json` 出 TOON 信封，`--yes` 恒由 actl 消费剥离（ark 无自拥 --yes 面）。
- 文档同步：R013 契约表 install/update 行与 --llms 行、README 使用例与 agent CLI 面、AGENTS 命令映射两行、llms.txt 模块表四行、CHANGELOG Unreleased。
