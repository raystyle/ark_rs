# 2026-09-19 独立分发域集成 REQ-0013

## 总台派单

install/update 通道集成自升级仓独立分发域（用户令「ark 要集成有单独域的 CLI 升级」）。五域（ark/hst/officecli/reader/browse，reader 自有桶 reader-dl 其余 env 桶多域），键形与边车不变；单一真源 = 云 catalog 节键 mirror_domain（总台并行滚入重签），仓内禁第二份域表；ark 自更新通道未用独立域保持不动。

## 实现

- catalog：Tool 新增 mirror_domain 可选键加 mirror_base() 访问器（非空即专属域、空串/空白/缺省回落 env.ohmygh.com）。
- resolve：pin_direct 镜像主通道 URL 基址取该键（mirror_url_at 显式基址形）。
- download：download_asset_with_mirror_at（install 主链与 npm-tgz 两腿接线 def.mirror_base()；docker/evergreen/selfupdate 无专属域键保持 env 域形不动）。
- 文档：R001 字段表、R015 消费侧、README 镜像源段、AGENTS 头行、--llms 下载行与 llms.txt（表述覆盖独立域事实、零内部编号）。
- 测试三层：单测独立域/回落/空白三态、集成测临时 catalog 带键 query url 断言专属域、实弹待云 catalog 键滚到后 update reader 取证。
- 踩坑：临时 catalog 集成测漏 exe 字段被 platform_managed 闸 skip（补 dir/bin/exe 三平台）；两枚 clippy（missing Errors 段与 too_many_arguments）随批收。
