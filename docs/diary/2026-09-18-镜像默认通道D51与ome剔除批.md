# 2026-09-18 镜像默认通道 D51 与 ome 剔除批

## 总台派单

镜像优先转正为默认通道（飞轮正式单，用户两连发：「ark 为什么不是默认使用 ohmygh.com 获取元数据和下载！github 应该是兜底，不是默认流程」「各仓的自更新应该也是默认 ohmygh.com」）。实证病灶：五端 update/install 全量逐工具打 api.github.com，gh 未认证或凭证失效撞匿名 60 次/时配额（lan-win 30 项失败 exit 1、lan-mac 401、lan-linux 未 login、lan-ubuntu 无 gh）。

用户加令（批中）：「剔除更换 ome 这类关键字为 ark」。总台追加单：封新版令（browse/ark 两仓封新版，本仓 minor 升位，先收口镜像单再封）。

## 镜像默认通道 D51 与 ADR-0008 与 REQ-0010

三面翻转：

- 解析面：resolve_github pin 驱动（无 latest/tag/version 选项）零 GitHub API。新增纯函数 pin_direct：catalog pin 三键（tag/version/asset）在位即镜像资产域 URL 主通道、`Resolution.fallback_url` 承载 GitHub release 确定性下载直链（对象直链非 API）兜底；install/docker/npm-tgz 下载调用官方回落地址改取 fallback_url。D38「API 失败回落镜像」闭包删除（被默认通道收编）。pin 三键缺一或显式选项才打 API。
- 下载面：D44 机制不动，核对无回归；新增 ARK_MIRROR=0 官方优先逃逸阀（跳过镜像首试直走官方，is_mirror_off 纯核入测）。
- 自更新面：元数据镜像段读序先行（mirror_meta 核心提取）、GitHub API 兜底、双败报两段错误；ARK_MIRROR=0 反转读序（官方先行镜像回落）。=1 转正默认兼容 no-op。
- update 语义对齐：cmd_update 解析改 pin 驱动（ResolveOptions::default），云端「最新」定义改指镜像与 catalog；D49 三态与不回写锁定不动。私有仓工具（omc）update 从必败（latest 打 API 404）变镜像直装可用。

设计决策三枚（ADR-0008）：latest 保留上游最新语义（镜像无 latest 元数据，临时钉版工作流依赖）、上游新于 pin 不跟进（滚锁归数据面）、ARK_MIRROR=0 逃逸阀/=1 no-op。三问入回执待用户裁。

测试面：pin_direct 三件单测（镜像主通道 URL 形、显式选项不直装、pin 缺键无资格）、is_mirror_off 值域、离线集成测 query 零 API（断网面 + url=env.ohmygh.com 直证）。
